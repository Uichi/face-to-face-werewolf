# ランダム配役の導入

## Supabase

狩人の022まで適用した後、SQL Editorの新しいクエリへ `supabase/migrations/202610060023_random_composition.sql` の全文を貼り付けて実行してください。成功したら公開ページを再読み込みします。既存SQL・テーブル・データは削除しません。進行中の試合を終えてから適用してください。

SQL未適用時はランダム設定を表示せず、従来の標準・カスタムを利用できます。

## 操作

主催者が待機室で「設定を変更」→「配役モード：ランダム」を選びます。占い師・霊媒師・騎士・狂人・恋人・パン屋・怪盗・狩人から候補を選び、「この設定を部屋に反映」を押してください。

人狼数は人数別の標準配役と同じです。村人を最低1人残す、有効な組み合わせからサーバーが等確率で選びます。恋人は必ず2人セット。他の特殊役職は各0〜1人です。候補として選んでも必ず登場するとは限りません。候補なしなら村人と人狼のみです。

実際の配役人数は主催者にも終了まで秘密です。本人の能力情報や人狼の仲間は従来どおり確認できます。パンの配達や狩人の発動などから存在を推測することはできます。パン屋が候補なら、配達なしの場合も朝の通知を表示し、未出現か死亡かは区別しません。

狼憑きは別設定で、抽選後の村人に従来どおり50%で0〜1人付きます。再戦は候補を維持して毎回抽選します。結果画面には開始時の配役人数と最終役職を表示します。

お気に入りにはランダムモードと候補も保存できます。プリセットを選ぶとランダムは解除されます。

## 確認

トップの一人試遊に「ランダム配役で試遊する」を追加しました。自分の役職も抽選されます。これはブラウザ内の試遊なので、実際の部屋ではSQL適用後に開始・再接続・再戦も確認してください。

自動テストでは5〜13人の組み合わせ、秘密の人数、二重開始、終了時公開、再戦、旧操作口の拒否と既存役職を確認します。ランダム配役のバランスは保証せず、対面での試遊で調整します。
