# 開発手順

最初の到達点は、5人がそれぞれのスマホから参加し、試合終了と再戦まで完了できること。

1. 仕様とルールの基礎
   - 確定仕様の保存、配役・勝敗・投票・夜処理の実装と自動検証。
   - 次に段階の遷移、操作確定、タイマー、途中脱落のやり直しを実装する。
2. 参加の仕組み
   - React + TypeScriptの画面、Supabaseの匿名認証、データ構造、閲覧制限。
   - 部屋作成、招待、参加、再接続、主催権限。
   - サーバー側のトランザクション、二重送信対策、権限テスト。
3. 5人の試合
   - 待機室→役職確認→初夜→議論→投票→夜→結果→再戦を接続する。
4. 全役職とトラブル対応
   - 霊媒・騎士・複数人狼の操作画面、カスタム配役、主催権限の移行、脱落時のやり直し。
5. 実機検証と限定公開
   - 5人・8人・10人、Safari・Chrome、実際の対面試遊。
   - 情報漏えい・通信切断・24時間削除・回数制限を検証する。
   - ホスティングの料金・利用条件を確認して限定公開する。

GitHubへの接続は初期段階で行う。非公開リポジトリを推奨し、仕様書・コード・テストの変更履歴を保存する。GitHubへのコード保存と、ゲームの公開は別の操作とする。
