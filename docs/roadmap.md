# 開発手順

最初の到達点は、5人がそれぞれのスマホから参加し、試合終了と再戦まで完了できること。

## 完了した実装

- 招待・匿名参加・復帰・配役設定・主催者移行。公開サイトで参加確認済み。
- 役職確認→初夜→議論→投票・決選→処刑→夜→朝→勝敗→再戦。
- 占い・霊媒・護衛・複数人狼、選択後の確定、途中脱落と操作取消。
- Supabaseでのトランザクションと閲覧制限。ブラウザへ全役職や個別票を渡さない。
- 63件の自動テスト。5・8・10・11・12・13人でのSQLによる終了・再戦も確認。

## 次に行うこと

1. 既存のSupabaseにゲーム用SQLを追加する（[手順](game-setup.md)）。
2. 公開サイトで5人の試合を完走し、再戦する。
3. 8人・10人・13人、Safari・Chrome、通信切断・主催者交代を実機確認する。
4. 定期清掃の設定と24時間削除を実環境で確認する。
5. 対面試遊で配役・説明・議論時間を調整する。

GitHubへのコード保存とサイトの公開は別の操作です。実際の試合データと秘密の認証情報はGitHubへ保存しません。
