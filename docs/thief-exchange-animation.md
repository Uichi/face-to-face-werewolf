# 怪盗の交換・答え合わせ演出

## 遊び方
- 怪盗は役職確認で相手を選び、確定します。全員完了までは裏向きのカードだけが表示されます。
- 初夜に「あなただけの情報」を開くと、相手の裏向きカードが移動して新しい役職を表示します。本人だけに表示し、奪われた相手には通知しません。
- 同じ試合では初回だけ動きます。隠す・段階変更・画面離脱で秘密画面を閉じ、2回目以降は通常の役職表示になります。記録するのは試合・本人の識別子だけです。
- 終了時は勝利演出の後に全員向けの答え合わせを表示します。カードの移動後、怪盗と相手の開始時→最終役職を確認できます。結果画面にも残ります。
- スキップ・動きを減らす設定に対応。画像が読めなくても役職名を表示します。

## 導入
`202610220027_planned_players.sql` の後に、追加の `202610300028_thief_reveal.sql` をSupabase SQL Editorへ全文貼り付けて実行してください。古いSQLやデータは削除しません。

SQLは終了済み試合だけに正確な交換相手を返します。通常のゲーム処理、勝敗、得点、試合中の秘密情報は変更しません。繰り返し適用できます。

SQL未適用でも怪盗本人の演出と従来のゲームは動きます。終了後は既存の公開役職から相手が一意に分かる場合のみ答え合わせを表示し、村人から奪った場合など不明な相手を推測しません。

一人試遊の「怪盗の交換演出 → 初夜」「怪盗の答え合わせ → 結果」で確認できます。後者は「結果の演出をもう一度見る（試遊）」で再生できます。
