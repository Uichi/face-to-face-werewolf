# ボディービルダーの導入

## Supabaseへの追加

医者の024まで適用した後、SQL Editorの新しいクエリに `supabase/migrations/202610150025_bodybuilder.sql` の全文を貼り付けて実行します。成功したら公開ページを再読み込みしてください。既存のSQL・テーブル・データは削除しません。進行中の試合は終えてから適用してください。

未適用の間はボディービルダーの設定を隠し、従来の役職で遊べます。

## ルール

ボディービルダーは村側で、カスタム配役で0〜1人。標準配役では0人、初期勝利点は5点です。主催者は0〜10点に変更できます。

試合中1回だけ、人狼の襲撃に自動で耐えます。騎士・医者が襲撃を防いだ場合は耐久を消費しません。処刑、狩人の発砲、医者の2回目の注射、恋人の後追い、途中退場には耐えられません。夜は確認だけを行います。

耐えた朝は「あなただけの情報」に通知が届き、「筋肉で襲撃に耐えました。次の襲撃には耐えられません」と表示します。以降、自分の役職画面で「襲撃への耐久：使用済み」を確認できます。決着した夜の通知も本人の結果画面に表示します。全員には襲撃による犠牲者がいなかったことだけを表示し、耐えた理由や対象は公開しません。

怪盗が奪うと能力も怪盗へ移ります。奪われた人は村人となり、ボディービルダー表示を維持しても襲撃には耐えません。役職交換は初夜より前なので、取得時の耐久は未使用です。

特別な耐久貢献点は設けず、既存の勝利点・生存点・投票貢献点を適用します。再戦では耐久をリセットします。

## ランダム配役・試遊・画像

ランダム配役の候補に追加できます。新規の候補設定には含めますが、保存済みの候補には自動追加しません。お気に入り設定にも対応します。

一人試遊には「初回に耐える」「2回目の襲撃で死亡」「騎士の護衛で温存」「医者の注射で温存」「怪盗が奪う」の5場面を追加しました。

画像は `public/images/roles/bodybuilder.png` に入れてください。未配置でも役職名・説明・操作を表示できます。
