# サイト共通パスワードを設定する

## 1. 機能を追加する

1. `supabase/migrations/202609290012_site_password.sql` の全文をコピーします。
2. Supabaseの **SQL Editor → New** に貼り付け、**Run** を押します。
3. **Success. No rows returned** と表示されれば準備完了です。この時点では保護はまだ無効です。

以前のSQLは削除せず、今回の追加SQLだけを実行してください。同じSQLを2回実行する必要はありません。

## 2. 合言葉を設定して有効にする

SQL Editorで新しいクエリを開き、次を実行します。`ここを希望の合言葉に変更` の部分だけを変更してください。合言葉は12文字以上を推奨し、72バイト以内にします。

```sql
select app_private.configure_site_password($site_password$ここを希望の合言葉に変更$site_password$);
```

`"enabled": true` が表示されると有効です。合言葉は公開サイトやGitHubには保存されません。Supabaseには照合用のハッシュだけが残ります。

## 変更・無効化

変更するときは、上の `configure_site_password` を新しい合言葉で再実行します。以前に解除した全端末が無効になり、新しい合言葉の入力が必要になります。

一時的に保護を外す場合は、次を実行します。

```sql
select app_private.disable_site_password();
```

## 動作

- 正しい合言葉を入力したブラウザは30日間入力を省略できます。
- ブラウザの保存情報を消した場合や別のブラウザ・端末では、再入力が必要です。
- 5回間違えると、そのブラウザでは15分間入力できません。
- 招待URLから開いた場合も、合言葉の確認後に参加画面へ進みます。
- HTML・画像などの静的ファイルは公開されたままですが、未解除の端末からゲームのデータ取得や操作はできません。
