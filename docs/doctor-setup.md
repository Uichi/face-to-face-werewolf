# 医者の導入手順

023のランダム配役SQLまで適用した後、SQL Editorの新しいクエリに `supabase/migrations/202610060024_doctor.sql` の全文を貼り付けて実行してください。成功後に公開ページを再読み込みします。既存SQL・テーブル・データは削除しません。進行中の試合を終えてから適用してください。

待機室でカスタム配役に医者0〜2人を設定できます。標準配役では0人、初期勝利点は5点です。ランダム候補に選ぶと0・1・2人を含む有効な組み合わせから抽選します。保存済みの候補には自動追加しません。

初夜は注射しません。通常の夜に自分を含む生存者1人、または「注射しない」を選んで確定します。1回目はその夜だけ襲撃を防ぎます。注射された回数は試合全体で累計し、日付・間隔・誰から受けたかに関係なく2回目で死亡します。同夜に2人から注射されても死亡します。再戦で回数をリセットします。

護衛では2回目の注射による死亡を防げません。恋人の後追い・狩人の発砲まで処理してから勝敗、生存点、パンを確定します。公開ログには「2回目の注射を受けたため死亡」と表示しますが、医者の名前や秘密の注射履歴・累計回数は公開しません。

本人には自分の注射履歴だけを表示します。怪盗が医者を奪うと能力も移り、奪われた人の偽の注射は効果や累計回数に影響しません。

1回目の注射で襲撃を防いで対象が生存すれば貢献実績＋1です。同じ対象を護衛した騎士にも＋1を記録します。村側勝利時のみ、既存の上限3点以内で獲得します。

一人試遊に「注射で襲撃を防ぐ」「数日後の2回目」「医者2人の同夜注射」「狩人の発砲」「怪盗が医者を奪う」を追加しました。実際の部屋での確認はSQL適用後に行ってください。

画像は `public/images/roles/doctor.png` に入れてください。未配置でも名前・説明・操作を表示します。SQL未適用時は医者設定を隠し、従来のゲームを利用できます。
