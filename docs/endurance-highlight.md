# ボディービルダーの耐久演出

耐久を実際に使用した翌朝、本人が「あなただけの情報」を開いたときだけ、役職カードを約1.4秒間、金色に光らせます。文字・音・公開イベントは追加しません。役職カードを初めてめくる場合は、めくり終わってから光ります。

- 騎士や医者に守られた場合、奪われた能力の偽表示、脱落、過去の耐久結果には出ません。
- 同じ試合で一度だけ。再表示や再読み込み後も繰り返しません。保存するのは試合・本人の識別子のみで、役職・対象・耐久日付は保存しません。
- 閉じる・自動非表示・段階変更・画面離脱で秘密画面とともに消えます。動きを減らす設定では演出を省略します。
- 読み込み失敗時は既存の役職名による表示を維持し、操作やタイマーを待たせません。
- 追加SQLは不要です。既存の本人用の耐久状態のみを参照します。

一人試遊の「筋肉で初めての襲撃に耐える」で、秘密画面を開いて確認できます。「騎士の護衛で耐久を温存」「医者の注射で耐久を温存」では光りません。
