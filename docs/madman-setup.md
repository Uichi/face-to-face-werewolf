# 狂人を追加する

1. `supabase/migrations/202609280008_madman.sql` の全文をコピーします。
2. Supabaseの「SQL Editor → New」に貼り付けて「Run」を押します。
3. 「Success. No rows returned」を確認し、全員がゲームページを更新します。

8〜13人のおすすめ配役に狂人1人が入ります。5〜7人は標準では0人です。主催者は「設定を変更 → 配役を自分で決める」で、村人を1人減らして狂人を1人にするなど、人数を調整できます。

既にカスタム配役を保存していた部屋は、狂人0人の設定を保持します。「おすすめ配役」に戻すか、狂人を追加して保存してください。進行中の試合の役職は変わりません。次の試合から利用できます。

## 狂人のルール

- 人狼側の勝利で勝ちます。脱落していても勝利に含まれます。
- 人狼が誰かは分からず、人狼にも狂人の正体は分かりません。
- 占い・霊媒は「人狼ではない」。初夜の白通知も狂人が対象になることがあります。
- 夜に能力は使わず、共通の「確認」を行います。人狼の襲撃先は見えません。
- 人狼に襲撃されれば脱落し、騎士の護衛で守れます。
- 勝敗の人数計算では人間です。「人狼1・狂人1・村人1」ではまだ終了しません。

13人の標準配役は村人6・人狼3・狂人1・占い師1・霊媒師1・騎士1です。勝率は対面試遊で調整します。

自動テスト68件を通過しています。狂人の権限・白判定・襲撃・共通確認・人数判定と、従来の5役職設定との互換性を検証しています。Supabase実環境の設定反映と実機試遊は追加後に確認します。
