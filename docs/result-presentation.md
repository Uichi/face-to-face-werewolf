# 公開結果の演出

夜明けは2秒、死亡結果は1件4秒、その他の結果は3.5〜4秒、勝利は5秒で表示します。何件目かと、処刑・襲撃・注射・後追い・発砲の見出しを明示します。処刑は得票数を併記し、夜の直接死亡、恋人の後追い、狩人の発砲を順に表示します。秘密情報は使用しません。

「自動送りを止める」で表示を止めて読み、「次へ」で手動で進められます。「自動送りを再開」も可能です。スキップボタンまたはEscapeで結果へ進めます。ゲームのサーバー処理やタイマーを待たせません。狩人の操作待ちでは勝利を表示しません。

最初の取得は基準点にし、その後届いた新しい公開イベントだけを演出します。再読み込み・再接続・非表示からの復帰では、取得済みの結果を再生しません。保存する秘密情報や追加SQLはありません。動きを減らす設定では自動演出を省略します。

一人試遊の結果画面にある「結果の演出をもう一度見る（試遊）」で、場面から始めた場合も最後の投票・夜の演出を確認できます。通常の参加画面には再生ボタンを表示しません。
