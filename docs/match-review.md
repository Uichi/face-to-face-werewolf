# 試合後の振り返り

追加SQLなしで利用できます。終了後、勝敗の下に今回の得点・部屋の累計順位・再戦ボタンを表示します。

- 公開ログを日ごとに古い順で表示します。初夜は「最初の夜」、夜はその夜が始まった日付です。
- 最後の処刑について、保存済みの投票結果から得票数を表示します。記録されていない過去の得票数は推測しません。
- 得点はサーバーで確定した値を使います。「得点の理由を見る」は最終役職の採点条件の説明です。個別の投票・能力の対象や、非公開の実績は表示しません。
- 同点は同順位、表示順は入室順です。旧試合で得点やログがない場合は、その旨を表示します。
- 一人試遊の累計は、その試遊内の確定得点を確認するための表示で、保存されません。

検証: 自動テスト、公開用ビルド、スマホ幅の表示、通常の処刑による決着と狩人の発砲による決着を確認。
