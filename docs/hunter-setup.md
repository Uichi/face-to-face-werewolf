# 狩人の導入手順

## Supabaseへの追加

1. 狼憑きの `202610010021_wolfbound.sql` まで適用済みであることを確認します。
2. SQL Editorで新しいクエリを開き、`supabase/migrations/202610060022_hunter.sql` の全文を貼り付けて実行します。
3. `Success. No rows returned` が表示されたら、公開サイトを再読み込みします。

既存のSQLやテーブル・試合データは削除しません。022未適用時は狩人設定を隠し、既存のゲームを利用できます。更新中の試合は終えてから適用することをおすすめします。

## 使い方

待機室のカスタム配役に狩人を0〜1人設定します。標準配役では0人です。勝利点は初期5点で、0〜10点に変更できます。

処刑または人狼の襲撃で本物の狩人が死亡すると、全員に役職が公開されます。死亡した本人が生存者を選択し、「発砲する」で確定します。途中退場では発動しません。

発砲は護衛を無視し、恋人の後追いも処理してから勝敗が決まります。夜の生存点とパンはその後の生存状態を使います。本物の人狼を撃った実績は貢献点の対象です。

60秒を過ぎても自動発砲はありません。主催者は60秒延長でき、期限後は確認画面を経て発砲を中止できます。中止は公開ログに残ります。

怪盗が狩人を奪うと能力も移ります。奪われた人は村人となり、狩人と表示され続けても発砲しません。

## 一人で確認する

一人試遊には「処刑から発砲」「襲撃から発砲」「恋人を撃つ」「人狼を撃って村側勝利」「怪盗が狩人を奪う」を追加しました。発砲待ちでは本人の画面で対象選択・確定を確認できます。

一人試遊はローカルの確認です。SQL適用後は実際の部屋でも、死亡した本人の操作、主催者の延長・中止、再接続を確認してください。
