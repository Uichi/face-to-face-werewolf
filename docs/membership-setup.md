# 参加者の削除・退出を有効にする

1. `supabase/migrations/202609270004_membership.sql` の全文をコピーします。
2. Supabaseの「SQL Editor → New」で空の編集欄へ貼り付け、「Run」を押します。
3. 「Success. No rows returned」を確認し、全員の端末で公開ページを更新します。

既存の部屋作成用・ゲーム用SQLは再実行不要です。この追加SQL自体は再実行できます。実行だけで参加者や部屋が消えることはありません。

## 使い方

- **参加者を削除**：待機室で、主催者に表示される名前の横の「削除」を押します。
- **自分が退出**：待機室の下にある「部屋から退出する」を押します。主催者なら次の人へ権限を移します。最後の1人なら部屋も削除します。
- **端末の履歴を消す**：トップにある「部屋の履歴を消す」を押します。部屋の参加者一覧からも名前を消すには、待機室で退出してください。

削除・退出すると配役はおすすめに戻ります。削除された人も招待コードから再参加できます。削除された端末の画面は、次の通信確認でトップへ戻ります（表示中は通常15秒以内、画面を閉じていた場合は復帰時）。

試合中は主催者の「脱落扱い」を使って進行してください。試合終了後に「再戦」で待機室へ戻ると、参加者を削除・整理できます。

SQLの権限、再参加、二重送信、主催者移行、最後の退出での部屋削除、試合中の拒否を自動テストで確認しています。実環境での削除・退出の確認は、この設定追加後に行います。
