# 待機室の設定保持と新しい設定画面

## 変更

参加・退出・接続状態・累計ポイントなどで部屋の更新番号が変わっても、設定の入力と編集画面を維持します。実際の設定変更・主催者交代・別の部屋への移動時は保存済み設定に同期します。保存失敗時は入力を消しません。

カスタム配役では人狼・特殊役職を保持し、人数差を村人で調整します。退出で人数が不足しても特殊役職を勝手に削除せず、成立しない配役では開始できません。標準配役は従来どおり人数別配役、ランダム配役は候補を維持します。

設定画面は「基本ルール」「配役」に分け、プリセット・お気に入りと配点は開閉式にしました。プレビューには人数を増減する確認ボタンがあります。実際の参加者を操作するものではありません。

## SQLの適用

1. 025のボディービルダーSQLが適用済みであることを確認します。
2. SupabaseのSQL Editorで `supabase/migrations/202610220026_lobby_settings.sql` の全文を新しいクエリとして実行します。以前のSQLやテーブルは削除しません。
3. `Success. No rows returned` なら完了です。
4. 待機室でカスタム配役を反映し、参加・退出した際に村人数だけが変わり、時間・配点・役職設定が残ることを確認します。

画面の修正はSQL未適用でも動きます。ただし、保存済み配役のサーバー側の自動調整と退出後の配役保持には026の適用が必要です。未適用時に配役合計が人数と違う場合は、編集画面で内容を確認して部屋に反映してください。
