# 配役プリセットとお気に入り設定

主催者が待機室の「設定を変更」を開くと使えます。追加SQLは不要です。

- 標準：現在の人数の標準配役。人数の変更にも自動で追従します。
- 基本役職のみ：標準配役の狂人を村人に置き換えます。
- 特殊役職あり：村人を1人以上残し、使用可能なパン屋・狩人・怪盗を順に追加します。バランスは試遊で確認してください。

プリセットは5〜13人で利用できます。議論時間と配点は維持し、狼憑きは無効にします。選択後も配役を調整できます。カスタム配役は人数が変わったら設定し直します。

「今の設定を保存」で、画面上の配役・議論時間・勝利点・連続護衛・狼憑きを同じブラウザに1件保存します。次に作った部屋でも「保存した設定を呼び出す」で復元できます。人数が違う場合は村人数で調整します。村人が不足したり、未対応役職が含まれる場合は呼び出しを拒否します。標準配役として保存した場合は、呼び出す部屋の人数に合わせます。

プリセット選択・お気に入り保存・呼び出しだけでは部屋設定は変わりません。内容を確認して「この設定を部屋に反映」を押すと、既存のサーバー側検証を通して参加者全員に反映されます。

保存先は端末のブラウザです。別端末には同期しません。ブラウザの保存情報を削除すると失われます。参加者名・秘密の役職・試合履歴・累計ポイントは保存しません。「保存を削除」でお気に入りだけを削除できます。
