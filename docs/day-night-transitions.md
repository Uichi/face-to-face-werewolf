# 昼夜の切り替え演出

- 初夜・通常の夜への切り替えに太陽→月、初夜明けと夜の結果に月→太陽を表示。
- 表示時間は1250ms。説明文は追加せず、背景色とSVGのアイコンのみで表現。
- 既存の夜明けフレームを置き換えるため、死亡・後追い・発砲・勝敗の演出より前に1回だけ表示。
- 切り替え中は画面を操作可能。サーバー処理やタイマーは待たせない。スキップは切り替え部分だけを省略し、その後の死亡結果は維持。
- 初回取得・再接続は既存状態を基準として演出を再生しない。非表示・オフライン時は停止。動きを減らす設定では省略。
- 追加SQL・画像・効果音は不要。秘密情報は参照しない。

確認: 207件の自動テスト、公開用ビルド、昼→夜、夜→朝、既存の死亡結果への接続。
