# 狩人の最後の一発：表示演出

- 発砲待ちの公開画面と、公開ログの狩人発動演出に、狩人カードと金色の照準を表示します。
- サーバーが確定した公開の発砲イベントだけに、照準が収まる動きと短い金色の光を付けます。確定ボタンのクリックや送信中には発動しません。
- 発砲された人の表示に続き、恋人の後追い・勝敗・怪盗の答え合わせへ、従来と同じ順序でつなぎます。撃たれた人の役職は終了まで公開しません。
- 発砲中止には光の演出を付けません。既知のイベント・再接続の初回状態は自動再生しません。
- 既存のスキップ、自動送り停止、動きを減らす設定に対応。新しい説明文・画像・効果音・画面揺れ・派手な点滅は追加しません。
- ゲームの処理・タイマー・操作権限は変更しません。追加SQLは不要です。

一人試遊の「狩人を処刑 → 最後の発砲」「狩人を襲撃 → 最後の発砲」で発砲待ちを確認できます。「狩人が恋人を撃つ → 後追い」「狩人が最後の人狼を撃つ → 村側勝利」で結果の再生を確認できます。
