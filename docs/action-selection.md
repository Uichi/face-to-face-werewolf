# 対象選択と確定内容の表示

投票・決選投票、夜の能力、パン、怪盗、狩人の発砲について、サーバーが返した本人の選択を確定ボタンの直前に表示します。「誰も処刑しない」「注射しない」も明示します。人狼は実際の襲撃の確約ではなく「襲撃先として希望」と表示し、サーバーが返した希望度だけを併記します。

確定済みは本人用応答の confirmed が true の場合だけです。送信中・再送待ち・接続確認中・失敗は未確定と区別します。確定後の対象は「あなただけの情報」でのみ表示し、同じ段階で待っている間は再表示できます。次の段階に進むと表示を切り替え、行動履歴を追加保存しません。

夜・パン・怪盗の選択は秘密欄の中、投票と公開済みの狩人の選択は従来の操作欄に表示します。閉じた秘密欄と公開案内には確定した対象を出しません。20秒後・ウィンドウの非アクティブ化・非表示・ヘルプ・段階変更で秘密欄を隠します。対象を含む確認ダイアログも合わせて閉じます。

説明と選択内容は画面上の役職に従うため、怪盗に奪われた人にも交換を知らせません。医者の累計注射回数や他人の襲撃希望は使用しません。連続護衛設定は試合情報を優先し、未提供なら部屋設定を使います。前夜の護衛先が返される場合は該当ボタンを無効化し、最終的な対象の可否は従来どおりサーバーが検証します。

追加SQL・API変更は不要です。一人試遊で役職を選び、他のテスト参加者をまだ完了させずに自分だけ選択・確定すると、確定後の再表示を確認できます。
