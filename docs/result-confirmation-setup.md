# 結果確認の更新

処刑・朝の結果は、生存者全員が「結果を確認しました」を押すと次へ進みます。脱落者や脱落した主催者の確認は不要です。勝敗が成立した場合は、その場で終了画面へ進みます。

## Supabaseへの反映

1. 狂人追加の `202609280008_madman.sql` まで適用済みであることを確認します。
2. `supabase/migrations/202609280009_result_confirmation.sql` の全文をコピーします。
3. Supabase の SQL Editor → New に貼り付け、Run を押します。
4. `Success. No rows returned` が表示されたら、全員がゲーム画面を再読み込みします。

既存の部屋・試合を削除する必要はありません。同じSQLを再実行できます。更新前の画面では主催者の「次へ」が残るため、全員の再読み込みが必要です。

画面はサーバーの対応状態を確認します。SQL適用前は従来の進行方法を維持し、適用後に全員確認へ切り替わります。

## 確認

自動テスト73件を通過しています。主催者の脱落、最後の確認による即時進行、二重送信、古い段階からの操作拒否、未確認者の途中退場を検証しています。実環境とスマートフォンでの確認はSQL適用後に行います。
