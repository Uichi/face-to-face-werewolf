# 予定人数で事前に配役を準備する

## 使用方法

待機室の「設定を変更」から「予定人数」を5〜13人で選びます。1人で部屋を作った直後でも、予定人数に合う配役・議論時間・配点などを「この設定を部屋に反映」で保存できます。

予定人数を設定すると、参加・退出で配役は変更されません。参加状況は全員に「予定10人 / 参加7人・あと3人」のように表示します。予定人数と参加人数が違う間は開始できません。予定より多い参加も13人までは受け付け、主催者に設定変更を案内します。

人数を変更して始める場合は、5人以上集まった状態で「現在の人数に合わせる」を押し、内容を確認して反映してください。カスタム配役は特殊役職と人狼を維持して村人数を調整し、配役が成立しなければ保存を止めます。標準配役は人数別の標準を使用します。ランダムは候補を維持し、その人数の人狼数を固定します。

「設定しない」に戻すと、従来の参加人数に連動する方式になります。時間・配点・連続護衛・狼憑きは人数変更でリセットしません。お気に入り保存は設定人数で保存・呼び出しができます。再接続・再戦でも予定人数は維持します。

## Supabaseへの適用

1. 026 `202610220026_lobby_settings.sql` が未適用なら、先に全文を実行してください。
2. SQL Editorで `202610220027_planned_players.sql` の全文を新しいクエリとして実行してください。
3. `Success. No rows returned` と表示されたらサイトを再読み込みします。
4. 予定人数を設定し、1人で配役を保存できることを確認してください。

既存のSQL・テーブル・部屋は削除しません。既存の部屋は予定人数未設定から始まります。027が未適用のサーバーでは予定人数の操作を表示せず、従来のゲームを継続します。予定人数の開始制限は画面だけでなくサーバーでも確認します。
