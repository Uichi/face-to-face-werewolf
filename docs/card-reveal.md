# 初回の役職カード演出

各試合・参加者ごとに、初めて「あなただけの情報」を開いたときだけ、共通の裏面 `public/images/roles/card-back.png` から約0.65秒で役職カードを裏返します。同じ試合の2回目以降は即時表示します。怪盗の交換後も同じ試合の再表示では繰り返しません。再戦では新しい試合として演出します。

演出が終わるまで役職の説明や仲間の情報を隠します。隠す操作、画面を離れる操作、段階の変更は従来どおり即時に反映し、演出を中断します。20秒後の自動非表示も維持します。役職画像がない場合は役職名を表示します。画像読み込みが止まっても役職確認が進められるよう時間制限付きで表示へ移ります。

端末で動きを減らす設定を有効にしている場合は演出を省きます。

再表示で演出しないため、ブラウザには試合IDと参加者IDの組だけを最大100件保存します。役職・行動は保存しません。再読み込み・再接続でも記録を参照します。保存を禁止している場合も操作は継続できますが、その場合は再読み込み後の記録維持を保証しません。

追加SQLは不要です。一人試遊で新しい試合を始め、表示・隠す・再表示を試せます。
