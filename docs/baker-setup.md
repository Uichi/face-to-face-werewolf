# パン屋の追加手順

SupabaseのSQL Editorで `supabase/migrations/202609290013_baker.sql` の全文を実行してください。`Success. No rows returned` と表示されたら追加完了です。同じSQLを誤って複数回実行しても構いません。

SQL適用後に全員が公開ページを再読み込みすると、待機室のカスタム配役に「パン屋」が表示されます。既存の標準配役には自動追加せず、主催者が村人などを1人減らしてパン屋を1人に設定します。パン屋は0〜1人です。

## ゲーム中の表示

- パン屋は村側で、占い・霊媒では人狼ではないと判定されます。
- 夜の対象選択はなく、ほかの能力なし役職と同じく夜の確認だけ行います。
- パン屋が生存している翌朝は、全員へ「パン屋から焼きたてのパンが届きました」と表示します。
- パン屋の名前は公開しません。
- パンが届かない朝は、パン屋が配役にいないか、すでに脱落しています。
- 標準の勝利点は5点で、生存点・投票による貢献点はほかの村側と同じです。

SQL適用前の公開画面はパン屋を設定項目に表示せず、従来の7役職でそのまま遊べます。過去に開始した試合へパン屋を追加したり、役職を再配布したりはしません。

パン屋の専用画像は `public/images/roles/baker.png` として追加できます。画像がない間はパンの絵文字を使った仮カードを表示します。
