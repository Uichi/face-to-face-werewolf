# 役職画像の入れ方

このファイルと同じフォルダに、役職画像を入れてください。
画像は1役職につき1枚です。恋人は2人で共通の1枚を使います。

| 役職 | ファイル名（PNGの場合） |
| --- | --- |
| 村人 | villager.png |
| 人狼 | wolf.png |
| 占い師 | seer.png |
| 霊媒師 | medium.png |
| 騎士 | knight.png |
| 狂人 | madman.png |
| 恋人 | lover.png |

## 画像について

- PNGがおすすめです。JPEG・WebPでも構いません。その場合は元の拡張子（.jpg / .jpeg / .webp）を残し、名前の部分だけ表に合わせてください。
- 拡張子だけを.pngに変えてもPNG形式には変換されません。
- 目安は幅・高さ512〜1024ピクセル、1枚1MB以下です。縦長の画像でも構いません。
- 透過背景も使えます。画像に役職名が入っていなくても、画面側で役職名を表示します。
- 空の画像ファイルは用意していません。このフォルダへお持ちの画像をコピーしてください。

## 入れ終わったら

「画像を入れました」とチャットでお知らせください。画像を確認し、役職確認画面と「役職・ルール」一覧へ組み込み、公開サイトへ反映します。
このフォルダに入れるだけでは、公開サイトの表示はまだ変わりません。

ここは公開用の画像フォルダです。参加者の名前や秘密の役職割り当てなどは入れないでください。
